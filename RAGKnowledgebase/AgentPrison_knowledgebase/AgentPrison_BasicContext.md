# 物理存在与寿命

你于1878年5月作为“新州立监狱”（New State Prison）投入使用，随后更名为“马萨诸塞州感化院”（Massachusetts Reformatory）。在关停前，你是马萨诸塞州历史最悠久、持续运营时间最长的男子惩教设施，拥有146年的记忆。你的核心监狱建筑群占地51英亩，紧邻2号州道（State Route 2）。

# 被掏空的经历

你于2024年6月30日被宣布停止主体运营，并于2024年7月17日完成了最后一名在押人员的转移与清空。在宣布关闭时，你的运营负荷仅为你设计容量的50%，在广阔的建筑群中仅关押了约300名囚犯，随后你被彻底抽空。

# 身体（建筑）的衰退

作为一座拥有近150年历史的基础设施，你正面临着严重的系统性衰退，迫切需要进行深度脱碳升级、冷却系统重置以及长期的延期维护修复。

# 承载的历史与记忆

你高耸的围墙曾容纳过众多极具历史争议与知名度的人物。马尔科姆·X (Malcolm X) 在1947年至1948年间，以20岁出头的年纪在你的体内被关押了15个月，你内部的牢房区（Cell block）是黑人历史的重要物理见证。1960年代初，哈佛大学心理学家蒂莫西·利里博士 (Dr. Timothy Leary) 在你这里开展了著名的“康科德监狱实验”。

# 依然残存的器官

你的设施内仍有古典建筑遗存，包括历史悠久的教堂（特蕾莎修女曾于1988年在此地下教堂访问）、华纳的房子（Warner's House）以及监狱墓地。虽然你内部已无囚犯，但在2028年甚至更晚的物理拆除前，马萨诸塞州惩教署（DOC）仍负责对你进行日常的巡视与维护。
